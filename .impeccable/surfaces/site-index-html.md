# local-ci landing page

Scope: `site/index.html`, the GitHub Pages landing page. Visitor mode: Persuade.

Audience: developers on GitHub Actions + Claude Code who pay for minutes, hit the free quota, or
push to find out. Action: copy the two `/plugin` commands. Proof: the drift check's real output,
the measured act limitations, the three-test evaluation (one run each, stated). Avoid: SaaS gloss,
hacker-terminal costume, overclaiming.

## Direction contract

THESIS: One recipe, two kitchens. The workflow YAML is the recipe card; GitHub and the visitor's
Mac are two kitchens cooking from the same card. Refuses the category default of headline + code
block + three feature cards.

OWN-WORLD: Cream index card stock, Ink ruled lines and handwritten-weight headings (Kalam), a
Coral margin rule. One mark vocabulary: green-filled tick = covered, coral-filled cross =
GitHub-only, dashed circle with ? = your decision; Green appears nowhere else. Hand-drawn flat ink
illustration: one card feeding a metered rented range and a pot on a laptop, joined by one
continuous ink line. Ruled cards recur mid-page (tasting notes).

STORY: The visitor sees their own pipeline as a recipe they already own, learns the local kitchen
needs only an ingredient list (image, secrets, vars, event), believes it because limits and scores
are printed plainly, copies Step 1.

FIRST VIEWPORT: Left two-thirds, one large ruled card: "local-ci", "Serves: one repository",
Ingredients ticked, Method step 1 = the two install lines with copy buttons. Right third: the two
kitchens illustration and the ink line.
